# Cat System

## Overview
Cats are the core units of the game, serving as both collectibles and functional gameplay elements. Each cat is unique with individual traits that affect expedition performance and visual appeal.

## Core Cat Attributes
- **Name**: Player-assigned or randomly generated cat names
- **Age**: Affects cat appearance and potentially abilities
- **Gender**: Basic identity attribute
- **Breed**: Determines base cat appearance and characteristics
- **Pelt Pattern**: Visual pattern overlay on the cat's fur
- **Fur Colors**: Three customizable color slots for detailed appearance control
  - Fur Color #1 (Primary)
  - Fur Color #2 (Secondary) 
  - Fur Color #3 (Accent/Detail)

## Progression System
- **Levels**: Cats gain experience and level up through expedition participation
- **Experience**: Earned through successful expedition activities and minigames
- **Stat Growth**: Level progression improves cat capabilities for expeditions

## Perk System
- **Unique Traits**: Each cat can have 1-3 special perks that provide gameplay advantages
- **Individual Effects**: Perks like "+1 attack damage" or "10% damage reduction to all party cats"
- **Party Synergy**: Some perks affect the entire expedition party, encouraging strategic cat selection

## Customization System
- **Cosmetic Only**: Customization affects appearance but not behavioral traits or stats
- **Unlockable Content**: Customization options earned through gameplay progression or monetization
- **No Starting Options**: Players begin with basic cats and unlock customization through play

## Customization Categories
- **Fur Colors**: Modify the three color slots for endless color combinations
- **Pelt Patterns**: Change the visual pattern/markings on the cat's fur
- **Accessories/Clothing**: Items the cat can wear (collars, bandanas, etc.)

## Acquisition & Rarity
- **Player Trading**: Direct trades between players for specific cats
- **Player Marketplace**: Buy cats that other players have listed for sale
- **Wild Encounters**: Rare chance to find cats during expedition minigames
- **Breeding System**: Combine two existing cats to create a new offspring cat
- **Daily Shop**: Rotating selection of cats available for purchase, refreshes daily
